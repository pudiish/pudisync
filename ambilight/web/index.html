    Set up a new board over USB

    Plug the board into the Mac that runs the hub with a USB data cable. This puts it on your Wi-Fi and points the hub at it.

    This wipes the board: firmware, saved Wi-Fi, LED count, segments and presets are erased for good. Leave it unticked if the board already runs WLED.
