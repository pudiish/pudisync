# ADR-002: First Delivery Scope

- Status: Proposed
- Date: 2026-11-20

## Include

- Preserve Natural/Immersive, Vivid and existing Pulse compatibility.
- Add Cinematic and Trippy monitor styles.
- Audio Reactivity control embedded within styles.
- Separate Room Studio with Neon Coast, Aurora, Deep Ocean, Golden Hour and Hearth.
- Shared feature analysis, deterministic 1D procedural primitives, versioned configs, safety tests and UI.

## Defer

- True surround channel capture.
- Default predictive beat firing.
- ML genre/speech classification.
- 2D-only effects on 1D strips.
- Public scene marketplace, node editor and cloud sync.

## Rationale

A complete set of compelling working experiences is more valuable than implementing every proposed DSP capability before any mode is polished.
